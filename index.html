My Dark Sun Online SDL2 native port for Windows

2026-10-21

It is time to share a massive milestone for the project.
Since the very beginning of the project, I have been working in parallel on porting the original Dark Sun Online client to Windows and Linux. And finally, this side project has reached a fully functional stage - the alpha version of the Windows port using SDL2!
As a matter of fact, I used old-school methods for this. No AI helpers or trendy vibe-coding were involved in the process, which is exactly why it took so much damn time. But doing it completely by hand was worth every single reversed byte.
Anyone can get the alpha build for testing upon request on the project's official Discord. Feedback is mandatory :)

Running Dark Sun Online 'baremetal' on modern PC

2024-12-30

Can you run the Dark Sun Online client natively on a modern PC without using emulation or virtualization, just like in the good old days?
Yes, you can!
Today, I successfully launched the Dark Sun Online client and connected to my server from a PC based on a Coffee Lake processor, Z270 chipset, and using onboard Gigabit PCI-Express network card.
The root filesystem was set up on a USB flash drive (MBR) with FAT partition containing DOS 6.22 and Windows 3.x!
