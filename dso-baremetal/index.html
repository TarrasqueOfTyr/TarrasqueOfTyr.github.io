Running Dark Sun Online 'baremetal' on modern PC

2024-12-30

Can you run the Dark Sun Online client natively on a modern PC without using emulation or virtualization, just like in the good old days?
Yes, you can!
Today, I successfully launched the Dark Sun Online client and connected to my server from a PC based on a Coffee Lake processor, Z270 chipset, and using onboard Gigabit PCI-Express network card.
The root filesystem was set up on a USB flash drive (MBR) with FAT partition containing DOS 6.22 and Windows 3.x!
