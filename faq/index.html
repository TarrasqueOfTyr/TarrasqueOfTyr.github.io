FAQ

  • Project Status (September 2026)
    The server core has been successfully updated to version 2.8, the final official version of the original Dark Sun Online. While the project is still in development, public registration is officially open! Stay tuned to our channels to keep up with updates.

  • Dark_Sun_Online_START.bat - The official way to launch the game

  • mdark.exe - Main DSO client executable (DSO\resources\drives\c\DSO\mdark.exe)
    Always use the latest version of mdark.exe, as it includes important client-side fixes and updates. To get the latest version, message @crt0

  • sv.cfg - main DSO config file (DSO\resources\drives\c\DSO\sv.cfg)
    The format of the sv.cfg file is as follows:
    Line 1: Must be kept empty (do not delete it!)
    Line 2: Server address (e.g., 127.0.0.1)
    Line 3: Server port (e.g., 14903)
    Line 4: Your account credentials in the format login!password

    
127.0.0.1
12345
login!pass

  • Sound
    To enable or disable sound, press Space key on the DSO loading screen and select either the mss16 or No sound driver. To adjust the volume, press Alt+P to open the in-game settings and set your preferred level.

  • Animations
    By default, animations are off. To enable animations, press F6 in-game, or toggle them in Alt + P in-game settings.

  • Basic hotkeys
    F1 - Show in-game help
    F2 - List players in the region
    F3 - List all players on the server
    Shift - Skip the intro cinematic
    1..9 - Select dialog options with NPCs or during events
    1, 2, 3, ESC - Hotkeys for NPC/items popups: (1) TALK, (2) GET, (3) USE, (ESC) Close popup
    S,C,E - Main Menu shortcuts: Start game, Create character, Exit
    Ctrl + F7 - (DOSBox) Start/Stop video recording (saved to DSO\capture\\)
    Alt + F5 - (DOSBox) Take a screenshot (saved to DSO\capture\\)
